**NOTE**
The code is inspired by [Building a Quantum Key Distribution System with Qiskit: A Hands-On Guide to BB84](https://medium.com/@kejvikejvi/building-a-quantum-key-distribution-system-with-qiskit-a-hands-on-guide-to-bb84-7cc49ab72baa)
This project is a simple educational exercise, born almost as a game. Its only goal is to get a hands-on feel for the logic of the BB84 protocol and to get my hands dirty with the Qiskit library for the first time. It has no scientific or academic pretensions, but serves as a first practical experiment to explore the inner workings of quantum circuits.
